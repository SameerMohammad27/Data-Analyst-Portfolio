# 💳 Credit & Debit Transaction Dashboard | Power BI

## 📌 Project Overview

This project is an end-to-end **Banking Analytics Dashboard** developed using **Microsoft Power BI** to analyze credit and debit card transactions. It provides decision-makers with a comprehensive view of transaction performance, customer behavior, branch performance, and transaction risk through interactive dashboards and dynamic KPIs.

The solution is designed to transform raw banking transaction data into meaningful business insights using Power Query, DAX, and modern data visualization techniques.

---

## 🎯 Business Objectives

- Monitoring overall banking transaction performance.
- Tracking credit and debit transaction amounts.
- Identifying high, medium, and low-risk transactions.
- Analyzing customer transaction behavior.
- Comparing branch-wise performance.
- Monitoring monthly transaction trends.
- Enable interactive filtering for business users.

# 💡 Key Business Insights

- Credit and debit transaction values are almost evenly distributed.
- High-risk transactions account for approximately **20.43%** of total transactions.
- Main Branch and City Center Branch contribute the highest transaction volumes.
- Monthly transaction volume remains relatively stable with a noticeable decline in December.
- Customer activity is evenly distributed across branches.
- A small group of customers contributes significantly to overall transaction value.
- Interactive filters enable detailed branch, month, bank, and transaction-type analysis.
